# fullstack_developer_capstone


This is a comprehensive Full-Stack Capstone Project.

## Features
- Frontend: React application featuring Login, Register, Dealers, and Reviews.
- Backend: Django REST API providing the necessary endpoints.
- Database: MongoDB (Node.js) for storing dealership and review data.
- Microservice: Sentiment Analysis service deployed on IBM Cloud Code Engine.

## How to run
- Frontend: cd server/frontend && npm run build
- Backend: cd server && python3 manage.py runserver
